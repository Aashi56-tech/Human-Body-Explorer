# 🧬 Human Body Explorer

An interactive educational website designed to help students explore the major systems and organs of the human body in a simple, visual, and engaging way.

## 🌟 About the Project

Human Body Explorer is an interactive biology project that allows users to learn about different human body systems, their organs, functions, and interesting facts.

The goal is to make learning human biology more interactive than traditional textbook-based studying.

## 🚀 Features

- 🧠 Explore the Nervous System
- ❤️ Learn about the Circulatory System
- 🫁 Explore the Respiratory System
- 🍽️ Understand the Digestive System
- 🦴 Learn about the Skeletal System
- 💪 Explore the Muscular System
- 🧪 Discover the Endocrine System
- 🛡️ Learn about the Immune System
- 🔎 Search for organs and systems
- 🌙 Dark Mode
- 📝 Interactive Biology Quiz
- 📚 Educational facts and explanations
